<Update label="May 29, 2026" tags={["v0.30.0", "pre-release"]}>

## Updates

- **New `OLLAMA_IGPU_ENABLE` environment variable.** Integrated GPUs are now largely disabled by default to avoid performance regressions on systems with both an iGPU and a discrete GPU. Set `OLLAMA_IGPU_ENABLE=1` to opt back in.
- The `v0.30.0` pre-release has been refreshed with stability and packaging fixes. To install or update, follow the steps in [Getting started](/getting-started) using the latest pre-release version:

  ```bash
  curl -fsSL https://ollama.com/install.sh | OLLAMA_VERSION=0.30.0-rc31 sh
  ```

  On Windows:

  ```powershell
  $env:OLLAMA_VERSION="0.30.0-rc31"; irm https://ollama.com/install.ps1 | iex
  ```

## Known issues

- `nomic-embed-text` now lowercases inputs to match the model card. Earlier Ollama versions preserved mixed case; expect different embeddings if you previously relied on the old behavior.
- `laguna-xs.2` is not yet supported on Windows or Linux.
- `llama3.2-vision` is not yet supported on this build.

</Update>

<Update label="May 14, 2026" tags={["v0.24.0"]}>

## New features

**Codex App support in Ollama Launch.** Launch OpenAI's Codex desktop experience directly from Ollama to work on multiple Codex threads in parallel, with built-in worktree and git support.

```bash
ollama launch codex-app
```

Codex App includes:

- **Built-in browser** — load local servers and sites and annotate the page to request changes.
- **Review mode** — review code, leave comments, and iterate without leaving the app.
- **Recommended models** — `kimi-k2.6` (vision) and `glm-5.1` for difficult agentic tasks; `nemotron-3-super`, `gemma4:31b`, and `qwen3.6` for local use.

To restore the previous Codex App configuration:

```bash
ollama launch codex-app --restore
```

## Updates

- Reworked the MLX sampler for improved generation quality on Apple Silicon.

See [Getting started](/getting-started) to install or update Ollama.

</Update>

<Update label="May 13, 2026" tags={["v0.30.0", "pre-release"]}>

## New features

**New inference architecture (pre-release).** Ollama now supports `llama.cpp` directly instead of building on top of GGML, with compatibility for the GGUF file format. MLX is used to accelerate model inference on Apple Silicon.

We're gathering feedback on performance, stability, and memory usage during the pre-release. Known limitations: `laguna-xs.2` and `llama3.2-vision` are not yet supported on this build.

Install the pre-release on macOS or Linux:

```bash
curl -fsSL https://ollama.com/install.sh | OLLAMA_VERSION=0.30.0-rc22 sh
```

On Windows:

```powershell
$env:OLLAMA_VERSION="0.30.0-rc22"; irm https://ollama.com/install.ps1 | iex
```

</Update>
