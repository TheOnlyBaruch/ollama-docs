Ollama lets you download and run large language models (LLMs) directly on your machine. No internet connection required after setup, no API keys, no usage costs, no data sent to external servers.

You interact with models through a simple CLI, a local REST API, or official client libraries for Python and JavaScript. Everything runs on your hardware.

<Info>
  Ollama runs on macOS, Linux, and Windows. It supports CPU-only machines but
  runs significantly faster with a dedicated GPU.
</Info>

## Who is this for?

Ollama is built for developers, researchers, and ML engineers who want to:

- Experiment with open-source LLMs without cloud costs or rate limits
- Build local AI-powered applications with full control over the model
- Run sensitive workloads where data must stay on-device
- Test and compare models quickly without managing infrastructure

## What you can do with Ollama

- **Run models from the CLI** — pull a model and start chatting in seconds
- **Call the REST API** — integrate Ollama into any application using HTTP
- **Use the Python library** — build scripts and applications using `pip install ollama`
- **Switch between models** — run Llama, Gemma, Mistral, Phi, and dozens more
- **Generate embeddings** — produce vector embeddings for semantic search and RAG pipelines
